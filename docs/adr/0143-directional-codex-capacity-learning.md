# ADR-0143:方向性 Codex 容量学习(下界候选与上簇模型)

- 状态:Accepted
- 日期:2026-08-12
- 决策者:maintainer
- 影响范围:Codex quota estimator 的容量分类与置信度
- 取代:ADR-0141 §3 的对称竞争簇重学习;修订 ADR-0142 §3 的继承先验失效规则

## 背景

capacity 候选 `candidate = local_cost × 100 / Δ%` 的误差源按方向并不对称:

- **压低候选**:外部消费推高分母、本地漏计成本——无界,且外部消费(手机/官方 CLI 并用)是常态;
- **推高候选**:入账时序错配与百分比量化——有界(铸造阈值 ≥5% 时约 ±10%)且近似零均值;区间内
  未检出的 reset 被 `reset_at` 检测排除。

样本分布因此是"真值附近的窄簇 + 无界的低侧长尾"。对称 median/MAD 加同侧竞争簇在低侧长尾成为
多数时会把中心拖低;持续外部消费产生的一致低样本与"容量真的变小"在数据上不可区分,竞争簇替换
机制会主动学入错误的低容量。而官方百分比本身已包含外部消费,`used = capacity × 官方百分比` 的
投影只要 capacity 不被拖低就始终正确——对称模型恰恰破坏了这一点。

## 决策

### 1. 下界候选与上簇

每个干净候选是容量的**下界估计**。accepted samples 构成一个自身一致的**上簇**:

- 簇中心为簇内 median;接受带宽为中心的 ±25%;
- 带宽内的候选进入簇(FIFO,上限 9,带 epoch 标记),清空 pending 高样本并把低样本连击计数归零;
- 簇为空时首个有效候选直接建簇。

### 2. 只允许重复可信高样本向上修正

高于带宽的候选进入单槽 `pending_high`,状态 `outlier_rejected`(待确认):

- 下一个高候选与 pending 的比值不超过 1.25 时,两者整体替换旧簇(向上收养),否则替换 pending;
- 有界的推高噪声无法连续伪造互相一致的高样本,因此两个即可收养;费率卡上调方向的漂移由此收敛,
  收养后系统在本地 credits 单位内保持自洽;
- telemetry gap、查询失败、未计价区间、epoch 边界清空 pending;低候选是预期噪声,不清空 pending。

### 3. 低样本只降低置信度

低于带宽的候选与"有官方增量但无本地成本"的区间标记 `external_usage_suspected`,推进
`low_streak` 连击计数,**不进入簇、不修改 capacity**。`low_streak ≥ 2` 时置信度持续为
`degraded`,直到出现簇内样本。gap 类区间不影响该计数。

### 4. 向下变化依赖 capacity-signature 证据

没有独立证据时容量永不自动下调。当前可用证据与既有机制一致:credential 身份指纹变化、窗口
ID/类型/时长变化(清空全部样本)、显式 reset credit 成功(删除 snapshot)。明确边界:

- 未重新登录的套餐降级会停留在高估容量,由持续 `degraded` 置信度提示,重新登录或显式 reset 解除;
- 费率卡下调方向的漂移同样表现为持续低样本,只降置信度;ADR-0141 已决定普通费率卡版本变化不作为
  epoch/signature 边界,本 ADR 不改变该决定。

### 5. 简化

`competing_samples`、同侧判断与 2/4 替换计数删除,替换为 `pending_high: Option<sample>` 与
`low_streak` 计数;median/MAD 退出分类决策,`relative_mad` 仅保留为展示诊断。ADR-0142 §3 的
"纯继承模型由 2 个反向候选推翻"作废:向上修正恒为 2 个一致高样本,向下恒不自动,与是否继承无关。
快照仍为 v7(Migration 0027 尚未发布,payload 原地修订)。状态枚举与管理 DTO 不变,
`outlier_rejected` 语义收窄为"偏高样本待确认"。

## 结果

- 持续外部消费不再拖低容量,used/remaining 投影在混用场景下保持正确;
- 容量修正的两条路径(重复高样本向上、signature 向下)都有明确的物理解释;
- 状态与分支数量净减;
- 代价:无 signature 的真实容量下调只能表现为持续 degraded,不再被自动吸收。

## 验证

估算测试覆盖:低候选不改容量且连击降级、两个一致高样本向上收养、单个高样本不收养且被簇内样本
清除、继承先验不被低样本推翻、继承先验被两个新高样本向上修正、冷启动低簇经高样本收养恢复真值。
