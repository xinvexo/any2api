# ADR-0012: 进程内会话粘性与固定 Credential 等待

- 状态：Superseded by ADR-0062
- 日期：2026-07-19
- 决策者：maintainer
- 取代者：ADR-0062

> 历史说明：本文原先采用“软/硬”两类绑定，并为普通会话提供 `prefer` / `strict` 模式和等待超时后的自动重绑。这套已实现但不必要的分类已于 2026-07-29 被 ADR-0062 完整删除，不再代表当前架构或兼容要求。

## 被取代的决策范围

ADR-0012 首次确定了以下仍然有效的基础边界：会话状态只保存在进程内；原始会话标识进入 Runtime
后立即转换为带用途域的不可逆 HMAC 键；并发首次请求通过版本化 `Creating` 租约避免选择分裂；
固定 Credential 等待复用全局有界 QueueTicket；Response ID 必须在对客户端可见前完成绑定；绑定、
Creating 状态和 HMAC 密钥在进程重启后全部清空。

原决策同时引入了两套绑定强度、不同 TTL、可选模式和自动重选规则。该部分增加了状态分支、设置项、
管理 DTO 和测试矩阵，却没有对应的产品需求，因此不再保留。

## 当前决策

所有当前会话绑定规则、设置、管理契约和迁移要求统一由
`docs/adr/0062-unified-session-affinity.md` 定义。
