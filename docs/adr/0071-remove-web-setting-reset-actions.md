# ADR-0071: Web 移除 SettingRegistry 恢复默认入口

- 状态：Accepted
- 日期：2026-07-30
- 决策者：maintainer

## 背景

SettingRegistry 使用编译默认值和 SQLite 用户覆盖值计算生效配置。此前 Web 在每个已有覆盖的设置行
提供“恢复默认”按钮，并把删除覆盖记录作为当前页面的一种草稿变更。个人管理面不再需要暴露这项
快捷操作；设置行应只承担编辑具体值的职责，避免同一控件同时表达写入值和删除持久化记录两种语义。

## 决策

- Web 删除全部“恢复默认”按钮、对应草稿状态、事件处理和浏览器侧调用路径。
- Web 保存设置时只提交具体覆盖值。管理员把值改成当前默认值时仍写入显式覆盖，以隔离未来版本的
  默认值变化。
- 设置读取契约继续返回默认值、覆盖值和生效值，现有 SQLite 覆盖记录不迁移、不删除。
- Domain、Storage、ConfigPublisher 与管理 API 继续保留删除覆盖记录的能力，供显式 API 管理和底层
  契约使用；该能力不在浏览器界面暴露。
- 本决策仅取代 ADR-0011、ADR-0039 及后续设置 ADR 中关于 Web 提供恢复默认入口的部分，不改变
  SettingRegistry、配置 revision、事务发布或热更新边界。

## 后果

设置页不再出现行级恢复按钮，也不会因清除覆盖而产生待保存状态。Web 用户只能保存一个具体覆盖值；
需要删除覆盖记录的自动化仍可使用既有管理 API。去除该入口不会修改运行中配置，也不会自动把现有
覆盖值替换成默认值。

## 验证

- Web 源码和可访问树中不再包含“恢复默认”按钮；
- 设置编辑器只构造 `updates`，批量请求中的 `resets` 固定为空数组；
- 设置页仍能编辑、校验、批量保存、处理 revision 冲突和刷新草稿；
- 管理 API、Runtime 与 Storage 的覆盖删除契约继续通过既有测试。
